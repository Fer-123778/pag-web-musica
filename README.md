# Música Hub
Diseño del sitio web de música.

Enlace a Figma: https://twice-satin-42519228.figma.site/

# Maquetación
- 14 vistas: Inicio, Explorar, Noticias, Géneros, Rankings, Buscador, Perfil de artista, Ficha de canción, Álbum, Mi biblioteca, Perfil, Contacto y Configuración.
- Hecho con React + Vite y estilos con Tailwind CSS (generado con Figma Make).
- Código formateado con Prettier.
- Accesibilidad: ver AUDITORIA.md.

Sitio en vivo: https://pag-web-musica.vercel.app/
